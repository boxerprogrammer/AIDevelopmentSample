## puyo-game
いわゆるぷよぷよです。対戦もありますし、難易度も上がっていきます
### プロンプト
```text
HTML5 Canvasと純粋なモダンJavaScript（ES6+）を使用し、CPU対戦機能を備えた本格的な「ぷよぷよ」風アクションパズルゲームを一括作成してください。
外部ライブラリや外部画像・音声アセットは一切使わず、すべてCanvas API描画およびWeb Audio APIの波形合成で自己完結させてください。
ブラウザですぐに遊べるよう、コード作成後にローカルWebサーバー（python3 -m http.server 8000 など）を自律起動してアクセスURLを表示してください。

【1. アーキテクチャとファイル構成】
責務を明確に分離し、以下のファイル構成で作成してください。
- index.html : スタイリッシュなダークテーマUIレイアウト、2面画面（Player vs CPU）の配置
- style.css : レトロアーケード風のフォント設定、アニメーション、レスポンシブな盤面デザイン
- js/
  - audio.js : Web Audio APIによるプログラミングBGM・効果音合成エンジン
  - visual.js : ぷよの目・表情・連結グラフィック描画、パーティクル爆発エフェクト
  - board.js : 盤面データ（横6×縦13）、BFS連結探索、ちぎり落下、連鎖解決ロジック
  - ai.js : CPUの配置思考ルーチン（ステージごとの思考深さ・連鎖狙い・ミス率）
  - game.js : ゲームループ、シーン遷移、入力管理、おじゃまぷよ送受システム
  - main.js : 全体初期化、ローカルストレージ連携、エントリーポイント

【2. ゲームシステム & CPU対戦仕様】
- 画面構成:
  - 画面左にプレイヤーフィールド、画面右にCPUフィールドを並列配置。
  - 中央にNEXTぷよ枠、予告おじゃまぷよ表示枠、ステージ進行状況を表示。
- おじゃまぷよ（相殺・降灰）システム:
  - 連鎖数・消去数に応じた攻撃力計算テーブルを実装。
  - 連鎖終了時に相手側の予告枠におじゃまぷよストックを追加。
  - 自身が連鎖した場合は「相殺」を行い、相殺しきれなかった分が相手の操作ぷよ設置後に上空から降る仕様。
- ステージ制とCPU難易度（Stage 1〜5）:
  - Stage 1（初級）: ランダム寄りの配置、思考遅延が長く、ミス率高め。
  - Stage 2〜3（中級）: 同色を隣接させる平積み傾向、2〜3連鎖を自然に組む。
  - Stage 4〜5（上級・ボス）: 盤面スキャンによる最大連鎖狙いのシミュレーション思考、高速落下。
  - CPUの盤面が詰まる（3列目の天井到達）とステージクリアとなり、演出後に次ステージへ進む。

【3. ぷよのビジュアル・演出要件】
- ぷよの連結表現:
  - 単純な丸ではなく、上下左右に同色のぷよが隣接している場合、境界をくびれなく結合する形状を描画（Canvasのベジェ曲線や矩形合成を使用）。
  - 各ぷよに白目・黒目・ハイライトを描画し、時折まばたきするアニメーションを付与。
- 派手な消滅・連鎖演出:
  - 4個以上揃った瞬間、ぷよがブルブルと震えて発光。
  - 消滅時に該当色のパーティクル（小粒子20〜30個）が放射状に弾け飛ぶ。
  - 連鎖発生時、画面中央に「1 CHAIN!」「2 CHAIN!!」「FEVER!!!」等のダイナミックなテキストカットインと画面揺れ（Screen Shake）を発生。

【4. Web Audio API によるBGM & 効果音】
外部音源は使わず、すべてオシレーターで合成してください（ユーザーの初回操作でAudioContextをResume）。
- BGM:
  - テンポの良いチップチューン風BGMループ（ベースライン＋アルペジオメロディ）。
  - ステージが上がるごとにテンポ（BPM）を少し上昇させる。
- SE（効果音）:
  - 回転音（ピピッ）、移動音（コツッ）、設置音（ポヨン）。
  - 連鎖ボイス代替SE: 1連鎖、2連鎖、3連鎖…と音程が階段状に上がっていくチャイム/アルペジオ音。
  - おじゃまぷよ落下音（ドガガガッ）、危険アラート音、勝利/敗北ファンファーレ。

  1. タイトル画面: STARTボタン、ハイスコア一覧ボタン、操作説明。
```

## race-game
いわゆる疑似3Dレースゲームです。正直思ったふうにできてません。
パズルやブロック崩しとは異なり、なかなか意図したものが伝わってない感じはします。

### プロンプト
```text
# 指示: レトロスタイル疑似3Dレーシングゲームの実装

クラシックなアーケードゲーム（OutRun風）の疑似3Dラスタースクロール方式を用いたレーシングゲームを、HTML5 Canvasと純粋なJavaScript（単一ファイルまたはモジュール分割）で新規実装してください。外部アセット画像への依存は避け、すべてのグラフィック（車、背景、障害物、UI）はCanvas 2D APIによる描画またはプロシージャル生成（ImageData / ベクターパス）で完結させてください。

---

## 1. コアグラフィックス & 疑似3Dレンダリング仕様
1. **疑似3Dコース描画（ロードスキャンライン方式）**:
   - コースは複数のセグメント（ライン）で構成し、カメラ座標（Z位置）とパースペクティブ投影を用いて手前から奥へと描画すること。
   - セグメントごとに曲率（カーブ）と勾配（アップダウン）のパラメータを持たせ、カーブに合わせて道路全体が左右にしなるような遠近法変形を実装すること。
   - コースの路面、縁石（赤白ストライプ）、芝生は、セグメントの偶数/奇数パターンをプレイヤーの前進速度に応じてテクスチャスクロールさせて表現すること。
2. **多重スクロール背景**:
   - 最背面に空、山並み、遠景のビル/木々などのレイヤーを配置すること。
   - プレイヤーのハンドル操作（横移動）および現在のコース曲率に応じて背景のXオフセットを視差スクロール（パララックス）させること。
   - プレイヤーの移動速度に応じて、遠景の流れる速度も自然に変化させること。

---

## 2. 操作系 & 車体物理挙動
1. **キーボード操作**:
   - `ArrowUp`: シフトアップ（ギアを上げる）
   - `ArrowDown`: シフトダウン（ギアを下げる）
   - `ArrowLeft` / `ArrowRight`: ステアリング操作（左右旋回）
   - `KeyZ` または `Space`: アクセル
   - `KeyX`: ブレーキ
2. **ギアシステム**:
   - ローギア（Low: 1速）とハイギア（High: 2速）の2段構成、または1〜4速構成。
   - ギアに応じた最高速度上限と加速力テーブルを設けること（例: 低速ギアは加速が鋭いが頭打ちが早く、高速ギアは低速時の加速が鈍いが最高速が伸びる）。
3. **路面判定**:
   - プレイヤーの横位置がトラック幅（アスファルト部分）をはみ出して路肩（芝生）に乗った場合、摩擦係数を上げて最高速度を大幅に減速（ペナルティ）させること。

---

## 3. オブジェクト & 衝突・大破システム
1. **コース沿いの障害物**:
   - 看板（Billboards）、ヤシの木/街灯などをコース脇の特定セグメントに配置し、パースペクティブスケーリングしてスプライト描画すること。
2. **ライバル車（NPC）**:
   - コース上に複数の他レーサー（NPC車）を走行させること。
   - NPCは一定速度で走行しつつ、プレイヤーの進路を塞ぐようなレーンチェンジ等の簡易AIを持たせること。
3. **衝突判定とクラッシュ挙動**:
   - 看板等の障害物やライバル車との接触判定をZ深度＋X位置で行うこと。
   - 衝突時:
     - プレイヤー車両は激しく回転・バウンドまたは破片が飛び散るクラッシュ（大破）演出を行う。
     - スピードはゼロに強制リセットされ、一定時間（約2〜3秒間）操作不能となる。
     - 復帰後はコース中央から低速（1速）でリスタートする。

---

## 4. ゲーム進行フロー & ステージ構成
以下の画面遷移ステートマシンを実装してください:

1. **Title Screen（タイトル画面）**:
   - タイトルロゴ、ハイスコア表示、「PRESS ENTER / SPACE TO START」の点滅。
2. **Pre-Race Screen（ステージ紹介画面）**:
   - これから挑むステージ番号、ステージ名、コースの全体マップ形状（2Dミニマップ等）を表示してカウントダウンまたはキー入力で開始。
3. **In-Race（ゲーム中）**:
   - 制限時間内にゴールラインへ到達することを目指す。
4. **Result Screen（レース結果画面）**:
   - 残り時間ボーナス、走行スコアの合算計算。
   - ハイスコア更新判定（`localStorage` へ保存・永続化）。
   - クリア時は「Next Stage」へ、タイムアップ時はゲームオーバー画面を経てタイトルへ戻る。
5. **ステージ設計（全5ステージ）**:
   - **Stage 1**: 初級（広い直線主体、緩やかなカーブ）
   - **Stage 2**: 中級（連続S字カーブ、適度なNPC）
   - **Stage 3**: 起伏（アップダウンの激しい丘陵、ブラインドコーナー）
   - **Stage 4**: 高難度（急カーブの連続、幅寄せしてくるNPC増加）
   - **Stage 5**: 最終（狭路、急激な勾配とタイトコーナーの複合）

## 5. UI（ヘッドアップディスプレイ / HUD）

- **Time Limit**: 残り時間（ゼロになるとゲームオーバー）
- **Score & High Score**: 現在スコアおよび保存されたハイスコア
```
