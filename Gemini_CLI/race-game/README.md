# OUTRUN RUSH - Retro Pseudo-3D Racing Game

クラシックなアーケードゲーム（OutRun風）の疑似3Dラスタースクロール方式を用いた、HTML5 Canvas 2D API ＆ Web Audio API による本格レーシングゲームです。
外部画像や外部音声ファイルへの依存は一切なく、単一の `index.html` で完結しています。

---

## 🎮 起動方法
ブラウザ（Chrome, Edge, Firefox, Safari等）で `index.html` を直接ダブルクリックして開くだけで即座にプレイ可能です。

---

## 🕹️ 操作方法

| キー / 操作 | 動作 |
|---|---|
| `Z` または `Space` | **アクセル**（加速） |
| `X` または `Left Shift` | **ブレーキ**（減速） |
| `←` / `→` または `A` / `D` | **ステアリング**（左右旋回） |
| `↑` または `W` | **シフトアップ**（HIGHギアへ） |
| `↓` または `S` | **シフトダウン**（LOWギアへ） |
| `Space` または `Enter` | **スタート / 画面送り** |
| `M` キー / 画面右上ボタン | **サウンド ON / OFF 切替** |

※ スマートフォンやタブレット等のタッチデバイスでも、画面上に表示されるバーチャルボタンでプレイ可能です。

## 🏎️ 車体物理 & ギアシステム
- **2段トランスミッション（LOW / HIGH）**:
  - **LOW（1速）**: 鋭い低速加速（0〜145 km/h）。スタート時やヘアピン立ち上がりで使用。138km/hを超えるとHUDに「SHIFT UP!」が表示されます。
  - **HIGH（2速）**: 高速巡航ギア（100〜292 km/h）。低速時の加速は鈍いですが、伸びのある最高速を発揮します。
- **路面摩擦ペナルティ**:
  - コース幅を外れて路肩（芝生・荒野）に乗ると、強烈な摩擦抵抗により最高速度が 85 km/h まで強制減速され、車体が激しくガタガタと上下に振動し土煙が立ち上ります。
- **カーブ遠心力（Centrifugal Force）**:
  - 高速でカーブに進入すると外側へ流される物理挙動を実装。カウンターステアやアクセルワークでラインを維持してください。

## 💥 衝突・当たり判定システム
- **精密な2DスクリーンAABB衝突判定**:
  - 画面上に見えている車のピクセル座標（2Dバウンディングボックス）と完全同期した判定システムを搭載。
  - 見た目通りの精密な当たり判定（車体サイズの約75%をヒットボックス化）により、隣の車線をすり抜けるスリリングなオーバーテイクが可能になり、「当たっていないのに突然クラッシュする」現象を根絶しました。
- **接触挙動の差別化（大破クラッシュ vs かすりバウンス）**:
  - **正面高速追突**: 自車の正面中央が相手の真後ろに高速突入（速度差50km/h以上）した場合のみ、大破クラッシュ（車体が宙に舞いスピン＆バウンド、破片四散、2.5秒停止後リスタート）が発生します。
  - **側面接触（かすり合い）**: 追い越し時や接触角度が浅い場合は、車体同士が火花を散らしながら弾き合って適度に減速（約18%）する「バウンス接触」となり、レースのスピード感を損なわずにバトルを継続できます。
- **コース脇障害物**:
  - 芝生上で看板やヤシの木の支柱・幹に直接激突した場合のみクラッシュが発生。縁石付近をギリギリで攻めるコーナーワークが可能です。

## 🏁 全5ステージ構成

1. **Stage 1: COASTAL BREEZE（初級）**
   - 広い直線主体、緩やかなヤシ並木の海沿いハイウェイ。
   - 制限時間: 60秒 / NPC数: 8台
2. **Stage 2: DESERT VALLEY（中級）**
   - 連続S字カーブ、赤土の岩山とサボテンが並ぶ砂漠コース。
   - 制限時間: 55秒 / NPC数: 12台
3. **Stage 3: ALPINE RIDGE（起伏）**
   - 激しいアップダウン（高低差）と先の見えないブラインドコーナーが連続する冠雪の山岳路。
   - 制限時間: 50秒 / NPC数: 14台
4. **Stage 4: METROPOLIS NIGHT（高難度）**
   - ネオン瞬く首都高速。タイトな急カーブと幅寄せブロックを仕掛けてくるアグレッシブなライバルたち。
   - 制限時間: 45秒 / NPC数: 18台
5. **Stage 5: VOLCANO CANYON（最終ステージ）**
   - 狭路、超急勾配、テクニカルな複合シケインが待ち受ける灼熱のファイナルステージ。
   - 制限時間: 45秒 / NPC数: 20台

## 🖥️ 画面フロー & HUD
- **TITLE**: ネオンロゴ、ハイスコア、PRESS SPACE TO START点滅、デモ走行。
- **PRE-RACE**: ステージ名、ステージ特徴解説、**2Dコース全体マッププロファイル**、カウントダウン（3, 2, 1, GO!）。
- **IN-RACE**:
  - Speedometer（km/h ＆ グラデーションバーゲージ）
  - Gear Indicator（LOW / HIGH、SHIFT UP! ナビ）
  - Time Limit（残り時間、10秒以下で赤色点滅警告）
  - Score & High Score（`localStorage` による永続保存）
  - コース全長プログレスバー ＆ 画面右上リアルタイムミニレーダー
- **RESULT**: 残り時間ボーナス加算アニメーション、ハイスコア更新判定、次ステージ進行。
- **ALL CLEAR / GAME OVER**: 全ステージ制覇のトロフィーエンディング、またはタイムアップゲームオーバー。
